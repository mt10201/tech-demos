# Photo → 3D → mold master: UniForge3D findings and the CPU pipeline

Checked 2026-10-22 for the owner's use: printed masters for silicone molds, **selling castings**,
on a CPU-only box (8 vCPU, 15 GB RAM, no GPU).

## UniForge3D: not added

| Item | Licence / need | OK for selling castings? |
|---|---|---|
| Code (GitHub) | MIT | yes |
| Weights (`xibushu/UniForge3D` on Hugging Face) | **CC BY-NC 4.0**, derived from `facebook/VGGT-1B` (CC BY-NC 4.0) | **no** — non-commercial only |
| Default background remover BRIA RMBG-2.0 | CC BY-NC 4.0 (commercial use needs a BRIA licence) | no, unless licensed or swapped (e.g. a permissive rembg model) |
| nvdiffrast (installed by its setup) | NVIDIA Source Code License, §3.3 "may be used … non-commercially" only | no |
| Runtime | CUDA only: torch 2.6 + cu124, flash-attn, CuMesh, FlexGEMM, TRELLIS.2 o-voxel | can't run here (no GPU) |

Whether a mesh generated by an NC model is itself NC is legally unsettled; the safe reading for a shop is
"don't sell castings from NC-weight output". So no torch/CUDA dependency was added to the app.

Alternative worth knowing: **TRELLIS.2** (Microsoft) is MIT for code *and* weights, but needs an NVIDIA
GPU with ≥ 24 GB VRAM (rent one, or run it on a desktop with an RTX 3090/4090). Its output still needs
the repair pass below before it is a printable mold master. Check every dependency's licence the same way
(nvdiffrast again is NC).

## What was added instead: `scan_repair.py` + `scripts/photo_to_master.py` + the "Photo → master" mode

Takes *any* mesh (AI image-to-3D GLB, phone scan, Sketchfab download) and makes a mold master:
orient → scale to a height in mm → patch holes → voxel closing (fills slots narrower than ~2 × `--close`)
→ flat base → keep the largest piece, fill bubbles, plug tunnels until genus 0 → marching cubes →
manifold3d decimation → checks (watertight, single shell, Euler 2, fits the Ender 2 150 × 150 × 200).
CPU only, uses existing requirements.

```bash
python scripts/photo_to_master.py model.glb master.stl --height 120          # GLB: +Y up is assumed
python scripts/photo_to_master.py assets/hayes_bust_npg_cc0.ply out.stl --damage-demo --preview out.ply
```

Demo (CC0 Hayes bust, 4 punched holes, 5 % flipped and 2 % duplicated faces, 3 debris spheres, an internal
bubble): rebuilt in ~4 s at 0.6 mm voxels / ~12 s at 0.4 mm; 120 mm tall, ≈ 98 × 59 × 120 mm,
watertight, 1 shell, Euler 2, fits the bed.
