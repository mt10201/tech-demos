# Tech Demos monorepo

One small demo per technology, each self-contained under `apps/<slug>/`.

Rules:
- Only add or change files inside `apps/<slug>/` for a demo (plus `tracking/seen-bookmarks.json`).
- Plan first with `skills/project-planning/SKILL.md`; write `apps/<slug>/PLAN.md`.
- Default stack: Python (uv or venv + requirements.txt). Each app has a README with exact run steps.
- Every demo PR must include at least one screenshot AND one video of the running app (put them in `apps/<slug>/media/`).
- Never create a separate repo per demo.
