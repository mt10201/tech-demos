---
name: project-planning
description: Turn a demo idea into a short, MVP-first plan.
---
1. State the goal in one sentence; define the single-user MVP and explicit outs.
2. Break it into a few outcome-oriented vertical slices.
3. Prefer prebuilt libraries and official starters over custom code; boring, documented defaults.
4. Pick one framework per project (Python default: Streamlit or FastAPI for UI/API, or a CLI for tiny utilities).
5. Lay out the folder structure before coding.
6. Test only critical logic. Keep tooling minimal.
7. Output: goal, MVP scope, tasks, stack with one-line rationale each, deferred items.
